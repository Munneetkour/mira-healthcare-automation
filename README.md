# MIRA – Medical Intelligence Robotic Automation

A front-end website project created to practice responsive web design and present a healthcare automation concept.

## Features
- Responsive navigation
- Hero section
- Project overview
- Healthcare automation cards
- Technology section
- Workflow section
- Dashboard/visual sections
- Contact form layout

## Technologies
- HTML5
- CSS3
- Responsive CSS Grid and Flexbox

## How to run
Open `index.html` in a browser.

This is a personal/learning front-end project. The healthcare automation descriptions are presented as a website concept and are not a claim of production deployment.
